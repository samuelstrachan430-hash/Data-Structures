# Data-Structures
This is an object oriented approach to stacks, queues and circular queues. 
Two python files. StacksQueues is required and is a dependiency to the Implimentation program. 
The StacksQueues file has the classes and raises errors if there is a e.g. dequeue when the queue is empty, there will be an error.  
The implimentation file handles the exceptions and calls the procedures validate.
